# 智能旅行规划助手

一个基于 AI 的智能旅行规划应用，集成 Google Gemini API 和 Google Maps Routes API，提供个性化的旅行建议和基于真实交通数据的行程规划。

🌐 **Live Demo**: [部署到 Vercel](https://vercel.com)

## 🌟 主要特性

- **AI 驱动规划** - 使用 Google Gemini 2.0 Flash 生成智能旅行建议
- **真实交通数据** - 集成 Google Maps Routes API，提供准确的交通时间和路线信息
- **智能行程优化** - 基于实时交通状况的多维度行程规划算法
- **动态 UI 生成** - 根据用户查询动态生成不同的组件组合
- **智能景点推荐** - 基于用户偏好和实时数据的景点推荐系统
- **交互式行程规划** - 可视化的行程时间线和拖拽式规划工具
- **响应式设计** - 适配桌面端和移动端的现代化界面
- **网络代理支持** - 内置代理配置，确保 API 访问稳定性

## 🚀 技术栈

- **前端框架**: Next.js 16 (App Router)
- **UI 库**: React 18 + TypeScript
- **样式系统**: Tailwind CSS
- **AI 集成**: AI SDK + Google Gemini API
- **地图服务**: Google Maps Routes API (通过 Gemini API 调用)
- **状态管理**: 自定义状态管理 + 观察者模式
- **网络请求**: Undici (代理支持)
- **开发工具**: ESLint + TypeScript

## 🛠️ 安装和运行

### 环境要求
- Node.js 18+
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 环境配置
创建 `.env.local` 文件并配置以下变量：

```env
# Google Gemini API Key (必需)
GOOGLE_GENERATIVE_AI_API_KEY=your_gemini_api_key

# 代理配置 (如果需要)
HTTP_PROXY=http://127.0.0.1:7890
HTTPS_PROXY=http://127.0.0.1:7890

# 可选的其他 API Keys
OPENAI_API_KEY=your_openai_key
DEEPSEEK_API_KEY=your_deepseek_key
```

### 启动开发服务器
```bash
npm run dev
```

访问 http://localhost:3000 查看应用。

## 🔧 核心功能

### 1. 智能旅行规划
- 基于自然语言查询生成旅行建议
- 支持多种查询类型：景点推荐、美食指南、行程规划等
- 动态生成不同的 UI 组件组合
- **NEW**: 集成 Google Maps Routes API 获取真实交通数据

### 2. 真实交通数据集成 🚗
- **实时路线计算**: 使用 Google Maps Routes API 获取真实交通数据
- **多种交通方式**: 支持驾车、步行、公交、骑行等交通模式
- **交通状况分析**: 实时拥堵情况和最佳出行时间建议
- **智能路线优化**: 基于当前交通状况的最优路径规划
- **优雅降级机制**: API失败时自动切换到备用计算（30km/h固定速度）

### 3. 智能行程优化算法 🧠
- **多维度约束**: 考虑游览时间、移动距离、交通时间等多个因素
- **智能评分系统**: 基于地理位置、时间适配度、交通便利性的综合评分
- **动态重新规划**: 添加或删除景点时自动优化整体行程
- **用户偏好保护**: 保留用户手动调整，只优化未锁定的部分

### 4. 景点智能推荐
- AI 驱动的景点分析和推荐
- 实时获取景点信息和评分
- 个性化推荐算法
- **NEW**: 基于真实交通时间的景点可达性分析

### 5. 交互式行程规划
- 可视化时间线展示
- 拖拽式行程调整
- 智能时间分配和路线优化
- **NEW**: 实时交通信息显示和路线详情

### 6. 性能优化系统 ⚡
- **路线缓存机制**: 避免重复 API 调用，提升响应速度
- **批量处理**: 同时处理多个路线查询，减少 API 调用次数
- **优雅降级**: API 失败时自动切换到备用计算方法
- **异步处理**: 不阻塞 UI 的后台数据处理

### 7. 网络代理支持
- 自动配置 Google API 代理
- 支持多种代理协议
- 智能 DNS 解析优化

- **批量景点处理**: 一次性添加多个景点，系统智能分配
