# 系统架构文档

## 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        用户界面层                              │
├─────────────────────────────────────────────────────────────┤
│  Next.js App Router  │  React Components  │  Tailwind CSS   │
├─────────────────────────────────────────────────────────────┤
│                        业务逻辑层                              │
├─────────────────────────────────────────────────────────────┤
│  Smart Planner  │  AI Services  │  State Management        │
├─────────────────────────────────────────────────────────────┤
│                        数据访问层                              │
├─────────────────────────────────────────────────────────────┤
│  Gemini API  │  Local Storage  │  Proxy Configuration      │
└─────────────────────────────────────────────────────────────┘
```

## 核心模块

### 1. AI 服务模块
- **Gemini Service**: 直接调用 Google Gemini API
- **Itinerary Service**: 专门处理行程规划
- **Response Parser**: 解析 AI 响应并生成 UI 组件

### 2. 智能规划模块
- **Smart Planner**: 核心规划算法
- **Attraction Intelligence**: 景点分析和推荐
- **Route Optimization**: 路线优化算法

### 3. 状态管理模块
- **Itinerary Store**: 行程数据管理
- **Attraction Store**: 景点数据管理
- **User Preferences**: 用户偏好设置

### 4. 网络配置模块
- **Proxy Setup**: 代理配置和管理
- **DNS Optimization**: DNS 解析优化
- **Request Interceptor**: 请求拦截和处理

## 数据流

```
用户输入 → AI 服务 → 智能规划 → 组件生成 → UI 渲染
    ↓           ↓         ↓         ↓         ↓
  验证处理   →  API调用  →  数据处理  →  状态更新  →  界面更新
```

## 技术决策

### 为什么选择 Next.js App Router？
- 服务器端渲染支持
- 内置 API 路由
- 现代化的开发体验
- 优秀的性能优化

### 为什么使用 Undici 代理？
- Next.js 内部使用 undici
- 更好的代理兼容性
- 原生 fetch 支持

### 为什么选择 Zustand？
- 轻量级状态管理
- TypeScript 友好
- 简单的 API 设计
